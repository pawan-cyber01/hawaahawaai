# Hawaa Hawaai Decor

A responsive business website for Hawaa Hawaai Decor, a balloon decoration and event decor service.

## Features

- Responsive design for desktop and mobile
- Decoration services and packages
- Image gallery
- Offers and pricing
- Customer enquiry/contact section
- Firebase integration for website data
- Modern and user-friendly UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Firebase
